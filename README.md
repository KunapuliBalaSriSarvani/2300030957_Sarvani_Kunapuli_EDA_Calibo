## My Learning

Through these tasks, I learned that data analysis is not only about writing Python code.

The important part is understanding:

**Raw Data → Data Inspection → Data Cleaning → Analysis → Visualization → Interpretation → Insights**

I also learned how different visualizations help answer different questions. For example, a histogram helps understand the distribution of a numerical variable, a boxplot helps identify possible outliers, and a heatmap helps understand relationships between multiple numerical variables.

Working with messy datasets helped me understand why data quality checks are important before performing analysis.
